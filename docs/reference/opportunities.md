# Oportunidades

Não existe nicho fixo inicial.

O Hunter procura onde existe demanda compatível com:

```text
capacidade real
×
retorno esperado
×
chance de fechamento
×
recorrência
×
baixo risco
```

Cada oportunidade recebe estado, score, fonte, contexto, evidência e próxima ação.

Oportunidades rejeitadas também devem registrar o motivo para evitar repetir pesquisa improdutiva.
