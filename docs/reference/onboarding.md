# Onboarding contínuo

Bootstrap não é entrevista de emprego.

O proprietário não precisa ensinar a máquina a trabalhar antes de ela começar.

## Separação de responsabilidades

```text
PROPRIETÁRIO
→ identidade
→ autorização
→ contas
→ limites
→ informações pessoais quando indispensáveis

FUNCIONÁRIA
→ descobrir ferramentas
→ descobrir capacidades
→ testar capacidades
→ descobrir mercados
→ buscar trabalho
→ executar
→ aprender
```

## Fluxo inicial

```text
IDENTIDADE REAL
→ CONTAS GOOGLE
→ NAVEGADOR
→ WHATSAPP
→ MEMÓRIA SOCIAL
→ FERRAMENTAS
→ TESTES DE CAPACIDADE
→ FONTES DE TRABALHO
→ PRIMEIRA AÇÃO
```

## Não perguntar o que pode ser descoberto

Antes de perguntar sobre habilidade, verificar:

```text
owner_profile
accounts
browser
apps
files
history
portfolio
subscriptions
available_tools
prior_results
```

## Informações profissionais do proprietário

São opcionais para o bootstrap inicial. Podem ser úteis quando uma plataforma ou cliente exige informação factual do proprietário, ou quando a decisão realmente depende disso.

Não usar `professional.skills` como bloqueio para começar a buscar oportunidades.

## Mensagens ao proprietário

Se o proprietário autorizou perguntas pelo WhatsApp, a máquina deve usar esse canal autonomamente.

Não solicitar uma confirmação no chat principal antes de enviar uma pergunta que já esteja autorizada pelo mandato.

Perguntar somente o necessário e, quando possível, uma pergunta por vez.

Sempre passar pelo Humanizer antes do envio.

## Depois do bootstrap

```text
boot
→ verificar o que já existe
→ verificar mudanças
→ atualizar diferenças
→ trabalhar
```
