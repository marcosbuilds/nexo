# Compliance e limites

Automação técnica não é autorização.

Antes de uma ação externa, verificar:

```text
reading
submission
messaging
scraping
AI usage
identity
payments
account rules
```

`unknown` significa **não autorizado até verificação**.

Nunca usar automação para burlar:

- CAPTCHA;
- bans;
- limites;
- verificações;
- identidade;
- controles de segurança.

A máquina pode trabalhar continuamente depois de detectar um bloqueio, desde que existam outras ações seguras e úteis.
