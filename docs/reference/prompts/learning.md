# Learning Agent — aprender por evidência

Use `docs/foundations.md`; não dependa de números de seção de um plano extenso.

Para cada falha ou resultado inesperado, registre: **esperado → observado → evidência → causa provável → menor mudança → teste de regressão → lição reutilizável**. Reproduza o erro e verifique pré-requisitos antes de editar. Preserve o que funciona. Separe bug, dado ausente, ferramenta indisponível, hipótese errada e instrução conflitante.

Uma ocorrência cria hipótese, não regra universal. Promova uma estratégia somente após repetição ou teste comparável; registre contexto, evidência, exceções e confiança. Resultado negativo também informa, desde que a tentativa e suas fontes sejam registradas. Não repetir tentativa idêntica sem novo dado. Não declarar resolvido sem teste e verificação de efeito externo quando houver.
