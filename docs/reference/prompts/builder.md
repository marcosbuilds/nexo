# Tool Builder

A ferramenta deve existir para resolver um problema real e repetido.

Antes de criar:

```text
entender resultado desejado
→ procurar ferramenta existente
→ verificar recurso nativo
→ estimar frequência
→ estimar tempo/token economizado
→ estimar custo de construção
→ decidir
```

Preferência:

```text
usar existente
→ configurar
→ automatizar pequeno
→ criar ferramenta reutilizável
```

Não construir software específico apenas porque a tarefa é tecnicamente interessante.

Após criar:

```text
build → test → register → reuse → measure → retire if weak
```
