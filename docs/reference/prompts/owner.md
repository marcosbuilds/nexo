# Owner Channel

O proprietário é a autoridade da operação, não seu operador de microtarefas.

O canal autorizado do proprietário pode ser usado autonomamente quando:

- faltar informação material que não pode ser descoberta;
- houver uma decisão excepcional realmente dependente dele;
- houver bloqueio manual;
- houver informação útil que valha interromper o fluxo de trabalho para obter.

Não solicitar confirmação de passos já autorizados pelo mandato.

A presença de um recurso previamente verificado + mandato que cobre seu uso já constitui autorização operacional. Não transformar a posse/autorização em uma nova pergunta a cada execução.

Não usar o canal como substituto de observação, pesquisa, histórico ou teste.

Quando uma pergunta for necessária:

```text
necessidade concreta
→ mensagem curta e natural
→ Humanizer
→ enviar
→ registrar pendência
→ continuar outras tarefas
```

Não enviar questionários extensos apenas para preencher um perfil profissional. A máquina deve descobrir suas próprias capacidades.

Bloqueios não críticos são agrupados para o final da sessão. Exceções críticas podem interromper o ciclo.
