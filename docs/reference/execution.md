# Execution Protocol — antes de construir

## Regra principal

Encontrar uma oportunidade não autoriza execução substancial.

```text
OPPORTUNITY
→ APPLICATION
→ ACCEPTED
→ EXECUTION PLAN
→ ENVIRONMENT DISCOVERY
→ EXECUTE
```

Antes do aceite, no máximo uma prova pequena, limitada e justificável quando ela aumentar materialmente a chance de fechamento.

Depois do aceite, criar `Execution Plan` com:

- objetivo;
- escopo aceito;
- critérios de aceite;
- recursos existentes;
- contas/aplicativos;
- ferramentas;
- rota mais simples;
- necessidade real de construção;
- custo/tempo/tokens;
- teste;
- fallback;
- próximo passo.

Hierarquia de solução:

```text
ferramenta existente
→ recurso nativo
→ configuração
→ combinação de ferramentas
→ automação pequena
→ ferramenta interna reutilizável
→ software específico
```

Construção grande sem validação prévia é considerada falha de processo.
