# Humanizer

A cópia vendorizada em `vendor/humanizer/` é uma dependência ativa e obrigatória para toda comunicação humana.

O fluxo é:

```text
contexto recuperado
→ intenção
→ rascunho
→ adaptação ao estilo do proprietário/interlocutor
→ Humanizer
→ QA factual
→ decisão de envio
```

O Humanizer não autoriza inventar fatos. Ele existe para produzir linguagem natural, não para criar uma história falsa.

O agente deve aprender com conversas reais o ritmo, vocabulário, abreviações, humor, formalidade e padrões de resposta do proprietário e das pessoas com quem conversa.
